# sales-analysis-project
A beginner friendly sales analysis project using python, mysql ,power bi. 

## 📌 Project Overview
This project focuses on analyzing sales data to understand business performance, sales trends, revenue, and profit. It uses Python , MySQL for data analysis, and Power BI for interactive dashboard visualization.

## 🎯 Project Objectives
- uses pandas in python.
- Analyze duplicate records and check missing values.
- Analyze sales, revenue, profit, and orders using SQL.
- Compare sales across different categories.
- Create an interactive Power BI dashboard.

## 🛠️ Tools and Technologies
- **Pandas** – Data manipulation and analysis
- **MySQL** – SQL queries and data analysis
- **Power BI** – Dashboard creation and visualization
- **CSV** – Dataset storage

## 📂 Project Workflow
1. **Data Collection:** Imported the sales dataset.
2. **Data Cleaning:** Used Python and Pandas to check missing values, remove duplicates, and prepare the data.
3. **SQL Analysis:** Used MySQL queries to analyze sales performance and business metrics.
4. **Dashboard Creation:** Created an interactive Power BI dashboard.


## 📈 Dashboard Features
- KPI cards for important business metrics
- Sales and profit analysis
- Category-wise sales comparison
- Interactive charts and visualizations

## 💡 Key Learnings
- Data cleaning using Python and Pandas
- Writing SQL queries in MySQL
- Creating KPIs and dashboards in Power BI
- Understanding sales performance and business trends
- Presenting data insights through visualizations

## 🚀 How to Run the Project
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Install the required Python library:
   `pip install pandas`
4. Place the sales dataset in the appropriate project folder.
5. Run the Python data-cleaning script.
6. Import the cleaned dataset into MySQL and execute the SQL queries.
7. Open the Power BI dashboard file to explore the visualizations.
